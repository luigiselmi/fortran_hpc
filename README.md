Fortran HPC
===========
Fortran examples for numerical methods.

## Compile and execute a Fortran program
We use the [GNU Fortran](https://gcc.gnu.org/fortran/) compiler to create an executable from a fortran file. The gfortran compiler can be installed on Linux and also on Windows with [Cygwin](https://www.cygwin.com/). In order to compile a fortran file use the command
''''
$ gfortran hello.90 -o hello
''''
The output will be an executable hello.exe
